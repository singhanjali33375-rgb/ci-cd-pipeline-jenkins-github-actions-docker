# End-to-End CI/CD Pipeline using Jenkins, GitHub Actions & Docker

## 📌 Overview
This project demonstrates a complete CI/CD pipeline implementation using Jenkins, GitHub Actions, and Docker. 
It automates build, test, containerization, and deployment of an application.

## 🛠️ Tech Stack
- Jenkins
- GitHub Actions
- Docker & Docker Hub
- Linux
- GitHub

## ⚙️ CI/CD Workflow
1. Code pushed to GitHub
2. GitHub Actions triggers CI pipeline
3. Application build & test
4. Docker image is created
5. Image pushed to Docker Hub
6. Jenkins triggers CD pipeline
7. Application deployed
